chdict

公开、纯静态、可跨域调用的中文词典 JSON API。包含成语、汉字、词语、歇后语数据， 任何人都可以直接用 fetch 读取，不需要后端，不需要鉴权。

This repository is a fork of pwxcoo/chinese-xinhua. 原始仓库来自这里，本站点只做静态 API 化整理与发布。

Base URL

所有 API 文件都在这个根路径下面：

https://chdict.leleleling.site/api/v1

Surge 通过项目根目录的 CORS 文件返回 Access-Control-Allow-Origin: *， 所以这个 API 可以被任意网站跨域调用。

试一下

这是纯前端 demo：浏览器加载索引，在本地过滤，再读取对应分片。没有向任何后端发送请求。

输入关键词开始查询。

快速开始

读取 manifest

const BASE = 'https://chdict.leleleling.site/api/v1';

const manifest = await fetch(BASE + '/manifest.json').then(r => r.json());
console.log(manifest.version);
console.log(manifest.datasets.idiom.count);

读取全量数据

const idioms = await fetch(
  'https://chdict.leleleling.site/api/v1/raw/idiom.json'
).then(r => r.json());

读取分片

const shardA = await fetch(
  'https://chdict.leleleling.site/api/v1/idiom/shards/a.json'
).then(r => r.json());

读取查询索引

const index = await fetch(
  'https://chdict.leleleling.site/api/v1/search/idiom-index-a.json'
).then(r => r.json());

API 路径

路径说明
/api/v1/manifest.json版本、数据量、文件清单
/api/v1/raw/{dataset}.json全量原始数据
/api/v1/{dataset}/shards/{a-z}.json分片完整数据
/api/v1/search/{dataset}-index-{a-z}.json轻量查询索引
/api/v1/search/{dataset}-char-map.json首字到分片映射
/api/v1/xiehouyu/random-pool.json歇后语随机池

dataset 可选：idiom、word、ci、xiehouyu。 shard 为 a 到 z。

查询是怎么工作的

因为这是纯静态 API，所以没有服务端搜索。推荐流程是：

  1. 加载 manifest.json
  2. 根据输入首字或拼音首字母确定 shard
  3. 加载对应的轻量索引文件
  4. 在浏览器本地过滤 key、pinyinAscii、abbreviation
  5. 命中后用 shard 和 offset 从分片中取完整记录

如果你只需要批量数据，直接读 /api/v1/raw/*.json 或分片文件即可。

限制

  • 没有服务端 ?q= 查询接口
  • 没有写入、鉴权、用户系统或限流
  • 静态资源通过 Surge CDN 分发，带宽额度以 Surge 套餐为准
  • Surge 具体套餐额度以官方说明为准
  • 全量 JSON 比较大，建议优先用索引 + 分片
  • CORS 对整个 Surge 项目生效，由根目录 CORS 文件统一控制
